# random

A dice-notation library for games, in **Java** (Gradle build).

The goal: parse the dice notation common in tabletop RPGs (e.g. `3d6+2`) into
random results, via `net.frohlich.random.DiceRoller`.

## Status

Stub. `DiceRoller` and `DiceRollerTest` are empty scaffolding — no parser is
implemented yet.

For a complete implementation of the same idea in Go, see
[`dice`](../dice).

## Build

```bash
./gradlew build
```
